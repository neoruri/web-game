## 3. ❌ 막힌 지점 — denoising 절벽

| denoising | ControlNet W | 캐릭터 | 포즈 |
|---|---|---|---|
| 0.52 | 1.0 | ✅ 유지 | ❌ 서 있음 (전혀 안 바뀜) |
| 0.60 | 1.2 | ✅ 유지 | ❌ 서 있음 |
| 0.62 | 1.4 | ❌ 교체됨 | ✅ 바뀜 |
| 0.66 | 1.4 | ❌ 교체됨 | ✅ 바뀜 |
| 0.68 | 1.4 | ❌ 교체됨 | ✅ 바뀜 |

**0.60 과 0.62 사이에서 급격히 전환된다.** 중간 지점이 없다.

### §6 표의 처방은 전부 시도했고, 전부 이 절벽을 못 넘었다
1. `denoising 0.52 → 0.60` — 포즈 변화 없음
2. `ControlNet Weight 1.0 → 1.2 → 1.4` — 변화 없음
3. `reference_only Unit 켜기` (weight 0.55 / style fidelity 0.6) — **0.62 에서 캐릭터 붕괴를 못 막음**
4. 스켈레톤을 **레퍼런스에서 추출한 것**으로 교체 — 캐릭터는 유지됐으나 포즈 여전히 안 바뀜

### ControlNet 이 안 걸린 것은 아니다 (확인함)
생성 결과 PNG 메타데이터:
```
ControlNet 0: "Module: None, Model: control_v11p_sd15_openpose_fp16, Weight: 1.4,
Resize Mode: Just Resize, Guidance Start: 0.0, Guidance End: 0.85,
Control Mode: ControlNet is more important"
Denoising strength: 0.6
```
Module 은 대문자 `None` 이어야 한다. 소문자 `none` 을 주면 조용히 무시된다 (Forge 실측).

## 4. 새로 밝혀낸 것 2가지 (절차 문서에 없던 내용)

### ① 초록 배경이 피부로 번진다 → **초기 이미지 배경을 회색으로**
denoising 을 올리면 화면의 65.8% 가 초록이라, 모델이 **초록 피부 엘프**를 그린다.
절차 문서의 Negative 에는 `green skin` 이 없다.

- `(green skin:1.6), (green face:1.5), (green legs:1.5), elf` 를 Negative 에 넣어도 **못 막았다**
- **초기 이미지의 초록 배경을 중립 회색(120,120,125)으로 치환하니 초록 피부가 사라졌다**

→ 초록은 **최종 크로마키용**이지 생성 중에 필요한 게 아니다.
   회색 배경으로 생성하고 나중에 초록을 합성하는 편이 옳다.
   생성해둔 파일: `tools/sprites/sd/init_idle_grey.png`

### ② 남는 실패는 **체크포인트의 인물 사전분포**다
회색 배경에서도 `(female:1.4)` 를 뚫고 **여성 아처 + 치마 + 맨다리**가 나온다.
denoising 이 높아지면 DreamShaper 8 자신의 사전분포가 프롬프트를 이긴다.

→ §0 은 "문제는 화풍이 아니라 캐릭터 동일성" 이라고 했는데 **절반만 맞다.**
   화풍(페인터리)은 확실히 맞지만, **인물 사전분포(여성 판타지 아처)가 안 맞는다.**
   낮은 denoising 에서는 init 이 억눌러서 안 보이다가, 높이면 그게 드러난다.

## 6. 다음에 시도할 것 (우선순위)

### ① 체크포인트 교체 후 같은 절차 재실행 — **가장 유력**
파이프라인·재료·프롬프트를 그대로 두고 **모델만** 바꾼다.
여성 사전분포가 약한 SD1.5 모델이면 0.62~0.66 구간에서 캐릭터가 버틸 수 있다.
검증은 프레임 3 한 장이면 판가름 난다. (약 2GB 다운로드)

후보: Deliberate v2 / ReV Animated / AbsoluteReality

### ② 회색 배경 init 을 기본으로 채택
①과 무관하게 적용할 가치가 있다. 초록 피부 실패를 원천 차단한다.
생성 후 초록 합성은 조립 단계에서 하면 된다.

### ③ 그래도 안 되면 — 절차 문서 §7
- 망토를 무릎까지로 재디자인 (다리를 덮는 구조적 원인 제거)
- run 을 4프레임으로 축소
- Gemini(nano-banana) 복귀 — 단, **빌링 필요**가 오늘 확정됐다
  (무료 티어는 이미지 생성 429. Gemini CLI 는 이미지 생성 기능 자체가 없음)
