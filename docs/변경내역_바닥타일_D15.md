## 1. 파이프라인

```
제미나이 생성 텍스처 (1024², 사용자 제공)
  → 중앙 832² 크롭        (테두리 비네트 60px + 워터마크 회피)
  → 패치 150² 무작위 추출  (16장 = 반복 패턴 제거)
  → 45° 회전               ★ 핵심
  → 2:1 눌러 다이아몬드
  → calm 0.85              (국소대비 완화)
  → D1.5 감마 1.45 / 대비 1.15
  → 림 44 + 알파 마스크
```

### 45° 회전이 핵심이었다
그냥 눌러 넣으면 원본의 **직교 줄눈이 다이아몬드를 가로질러 검은 십자선**으로 남아
깨져 보인다. 45° 돌리면 줄눈이 다이아몬드 변과 정렬돼 아이소 석재로 읽힌다.
회전은 **3배 해상도에서** 해야 한다 — 원본 크기에서 돌리면 보간 때문에 뿌옇게 된다.

### "심리스"는 필요 없었다
처음엔 심리스 처리를 하려 했는데, 아이소 바닥은 **각 다이아몬드가 독립 스프라이트**다.
타일끼리 픽셀이 이어질 필요가 없고 연속감은 톤에서 온다.
→ 큰 원본에서 서로 다른 패치 16장을 뽑는 것으로 문제가 사라진다.
(제미나이 결과는 실제로 상하 이음이 안 맞았다 — 끝단 차이 47.3 vs 내부 7.5)

## 2. 왜 D1.5인가 — 스프라이트를 얹어 판단했다

수치만으로는 판단이 안 돼서 **실제 고블린·엘리트·플레이어를 얹어** 비교했다.
(기존 타일셋에서 "그물망 같다"고 지적받은 게 이 검증을 안 해서였다)

| | 평균 명도 | 국소 대비 | 고블린 대비 | 엘리트 대비 |
|---|---|---|---|---|
| 기존 (절차 생성) | 61.8 | 1.06 | 13.9 | 21.4 |
| 3_calm (원본 톤) | 73.4 | 3.22 | **2.3** | 9.8 |
| D1 | 52.6 | 2.75 | 23.1 | 30.7 |
| **D1.5 (채택)** | **43.2** | **2.47** | **32.5** | **40.0** |
| D2 | 35.7 | 2.20 | 39.9 | 47.5 |

- 3_calm 은 고블린과 바닥 밝기 차이가 **2.3**밖에 안 됐다 → 어둡게 하는 게 옳았다
- D2 는 어두운 타일이 검게 뭉쳐 다이아몬드 격자 구분이 흐려지기 시작
- D1.5 는 국소 대비 2.47 로 기존(1.06)의 2.3배 → 질감이 살아 있다

### 어둡게 하는 방법
**단순 곱셈(×0.7)을 쓰지 않았다.** 밝기 차이도 같이 0.7배가 되어 대비가 죽고 탁해진다.
→ 감마로 중간톤을 누르고 대비를 되올려 형태를 유지했다.

### 관측: 밝기 대비 지표는 오지표였다
D1.5 이전 단계(2_toned)에서 고블린-바닥 밝기 차이가 **0.9**로 거의 같았는데
확대해 보니 문제없이 읽혔다. `gen_enemies.py` 에 **밝은 외곽선을 필수로** 넣어둔 덕이다.
→ 스프라이트 가독성은 평균 밝기보다 **윤곽선**이 좌우한다.

## 3. 3장을 같은 소스에서 만든 이유

stone 만 바꾸면 special·moss 가 기존 청회색으로 남아 톤이 어긋난다.

| | 명도 | 국소대비 | R-B | G-R |
|---|---|---|---|---|
| stone (신규) | 40.9 | 2.53 | +3.5 | +5.9 |
| special (신규) | 25.5 | 1.91 | +1.8 | +3.4 |
| moss (신규) | 39.8 | 2.45 | +2.8 | +8.1 |
| *(기존 stone)* | *63.6* | *1.06* | *−18.7* | *+8.4* |

R-B 가 −18.7(파랑기) → +3.5(초록기)로 바뀌었다. **R-B 편차가 3장 사이 1.7** 로 일관된다.

### special (깨진 6 + 구멍 4)
- 깨진 타일: 원본에서 **국소대비 상위 구역만 골라** 썼다(40장 뽑아 6장 채택).
  무작위로 뽑으면 멀쩡한 면이 섞여 "깨졌다"가 안 읽힌다
- 구멍: 절차 생성 유지하되 색조를 새 바닥에 맞춤. 평균 명도 9.4 로 확실히 구분됨

### moss
**색조만** 초록으로 기울였다(R−7 / G+11 / B−6). 명도는 stone 과 거의 같게 유지.
예전 이끼 타일이 "잔디 같다"고 지적받은 이유가 명도까지 올렸기 때문이다.

## 4. 🔴 남은 문제 — 프롭이 톤에서 튄다

| | 명도 | R-B |
|---|---|---|
| 새 바닥 | 40.9 | **+3.5** (초록기) |
| `props_iso.png` | **83.7** | **−20.9** (파랑기) |

무덤·기둥·부서진벽이 **바닥보다 2배 밝고 색조가 반대**다. 미리보기에서
"다른 조명 아래 있는 물체"처럼 떠 보인다.

### 대응 (아직 안 함)
`props_iso.png` 를 같은 감마(1.45/1.15) + 색조 보정으로 다시 뽑으면 된다.
단 프롭은 **보여야 하는 물체**라 바닥과 완전히 같게 만들면 안 된다 —
명도를 60 정도로 낮추고 색조만 초록 쪽으로 옮기는 선이 적절해 보인다.

`decals_iso.png`(명도 45.7 / R-B −10.4)도 약하게 파랑기가 있지만
데칼은 아주 옅어서(국소대비 0.75) 실제로는 거의 안 보인다 — 우선순위 낮음.
