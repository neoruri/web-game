# 스킬 트리 기획 — 사냥꾼 3계열 (레벨별 수치 상세)

> 뱀서류 로그라이크 밸런스 기준. 아직 기획 단계(코드 미반영).
> 기호: 🎯액티브(자동발동)  ⬆패시브(상시)  ⭐캡스톤(궁극)

---

## 밸런스 큰 그림 (왜 이 수치인가)

뱀서류는 **후반 물량이 폭증**한다. 그래서:

- **패시브 %는 선형**(레벨당 고정)으로 완만하게 — 한 노드에 몰빵해도 과하지 않게.
- **액티브의 진짜 성장은 "발수·개수·범위"** — 물량을 감당하려면 화살 수가 늘어야 한다. 데미지 %보다 발수가 체감이 크다.
- **쿨감은 상한 40%** (지능과 합산) — 스킬이 무한 난사되지 않게, 최소 쿨타임 1초 보장.
- **광역(다발·난사·수류탄) = 물량 담당, 단일(연발·치명타) = 보스 담당.** 두 축을 분리해 빌드가 갈리게.

투자 지침: 레벨 30까지 ~29포인트 → **한 계열(~14포인트) + 다른 계열 절반**. 매 판 다른 빌드.

---

## ① 정밀 사격 — 보스 킬러 (단일 폭딜·치명타)

```
[Tier 1] ─ Lv1 해금 ──────────────────────────────────
  ⬆ 궁술 숙련 (기본 활 피해)
       Lv1 +5%  →  Lv5 +25%   (레벨당 +5%)
       └ 투사체 속도도 레벨당 +3% (먼 적 명중률↑)
       ▶ 기본 활이 상시 딜의 근간. 초반 1순위.

  ⬆ 집중 (치명타 확률)
       Lv1 +2%  →  Lv5 +10%   (레벨당 +2%)
       ▶ 치명타 빌드의 관문. 아래 노드 선행.

[Tier 2] ─ Lv5 해금 ──────────────────────────────────
  🎯 연발 사격 (단일 대상 집중 연사)
       Lv1: 5발   Lv2: 6발   Lv4: 7발   Lv7: 9발
       Lv3~: 연사 속도 +18%   Lv9~: +추가 +28%
       Lv6: 관통 +1   Lv9: 마지막 화살 피해 ×2.5   Lv10: 마지막 화살 폭발
       발당 피해 = 무기 피해 × 50%
       기본 쿨타임 4초
       ▶ 보스에게 화살을 퍼붓는 주력기. 레벨업마다 발수가 핵심.

  ⬆ 치명타 훈련 (치명타 피해)   [선행: 집중 2]
       Lv1 +8%  →  Lv5 +40%   (레벨당 +8%)
       ▶ 크리 배수를 1.5 → 최대 1.9로. 집중과 세트.

[Tier 3] ─ Lv10 해금 ─────────────────────────────────
  ⬆ 관통 화살 (관통 수)   [선행: 궁술 숙련 2]
       Lv1 +1  →  Lv3 +3   (레벨당 관통 +1)
       ▶ 기본 활·사격계열이 적 여러 겹을 뚫는다. 일렬 물량에 강함.

  ⬆ 약점 간파 (보스·정예 추가 피해)   [선행: 치명타 훈련 2]
       Lv1 +6%  →  Lv4 +24%
       ▶ 일반 적엔 무효, 보스에만 적용. 순수 보스 특화.

[Tier 4] ─ Lv15 해금 ─────────────────────────────────
  ⬆ 저격 자세   [선행: 관통 화살 1]
       사거리 +10%(항상)  +  정지 후 0.5초 지나면 피해 +12%
       ▶ 자리 잡고 쏘는 플레이 보상. 기동형과 반대 컨셉.

  ⬆ 연발 강화   [선행: 연발 사격 3]
       연발 사격 발수 +2, 연사 속도 +15%
       ▶ 주력기를 한 단계 더. 연발 빌드 완성.

[Tier 5] ─ Lv20 해금 ─────────────────────────────────
  ⭐ 헤드헌터   [선행: 저격 자세 or 약점 간파]
       치명타로 적을 처치하면 그 자리에 관통 폭발
       (주변 적에 무기 피해 100%). 내부 쿨 0.3초.
       ▶ 치명타 빌드의 궁극. 잡몹을 크리로 터뜨리며 연쇄.
```

**정밀 사격 요약**: 힘(피해·크리피해)과 궁합. 보스를 빠르게 녹이지만 순수 단일이라 물량엔 관통·헤드헌터로 보완.

## ② 질풍 사냥 — 물량·기동·생존 (연사·광역·회피)

```
[Tier 1] ─ Lv1 해금 ──────────────────────────────────
  ⬆ 속사 (기본 활 공격 속도)
       Lv1 +4%  →  Lv5 +20%   (레벨당 +4%)
       └ 공격 속도 상한 +75% (민첩과 합산)
       ▶ 기본 활 연사력. 물량 상시 처리.

  ⬆ 회피 훈련 (회피 확률)
       Lv1 +1%  →  Lv5 +5%   (레벨당 +1%)
       ▶ 피격을 확률로 무효. 생존의 시작.

[Tier 2] ─ Lv5 해금 ──────────────────────────────────
  🎯 다발 사격 (전방 부채꼴 광역)
       Lv1: 5발   Lv2: 6발   Lv4: 7발   Lv7: 9발
       Lv3: 피해 +15%   Lv8: 피해 +20%(누적)   Lv6: 관통 +1
       Lv9: 적중 시 파편 화살   Lv10: 중앙 화살 폭발
       발당 피해 = 무기 피해 × 50%,  기본 쿨타임 3초
       ▶ 몰려오는 적을 부채꼴로 쓸어담는 주력 광역기.

  ⬆ 이동 강화 (이동 속도)
       Lv1 +2%  →  Lv5 +10%   (레벨당 +2%, 상한 +35%)
       ▶ 적을 끌고 다니는 카이팅의 핵심. 빠를수록 안전.

[Tier 3] ─ Lv10 해금 ─────────────────────────────────
  ⬆ 광폭 사격 (다발·난사 발수)   [선행: 다발 사격 2]
       Lv1 +1  →  Lv3 +3   (액티브 발수 추가)
       ▶ 광역 스킬의 화살 수를 직접 늘림. 물량 대응 최고 효율.

  ⬆ 피격 후 가속   [선행: 이동 강화 2]
       피격 후 2초간 이동속도 Lv당 +5% (최대 +15%)
       ▶ 위기 순간 탈출력. 공격적 회피 플레이.

[Tier 4] ─ Lv15 해금 ─────────────────────────────────
  🎯 난사 (주변 360° 연속 사격)   [선행: 다발 사격 3]
       지속: Lv1 1.5초 → Lv4 1.8초 → Lv8 2.2초
       Lv2: 발사 빈도↑   Lv9: 추가↑   Lv6: 관통 +1
       Lv7: 난사 중 이속 +10%   Lv10: 종료 시 원형 충격파
       발당 피해 = 무기 피해 × 50%,  기본 쿨타임 7초
       ▶ 포위됐을 때 사방으로 탈출구를 뚫는 광역기.

  ⬆ 전투 회피   [선행: 회피 훈련 2]
       회피 확률 +1.5%/Lv  +  회피 성공 시 0.3초 무적
       ▶ 회피가 단순 무피해를 넘어 짧은 무적으로. 탱킹형 생존.

[Tier 5] ─ Lv20 해금 ─────────────────────────────────
  ⭐ 화살 폭풍   [선행: 난사 or 전투 회피]
       난사 지속 중 뒤에 분신 생성(플레이어와 같이 난사)
       + 난사 중 이동속도 대폭↑. 종료 충격파 강화.
       ▶ 질풍 빌드의 궁극. 움직이며 사방을 화살로 덮는다.
```

**질풍 사냥 요약**: 민첩(공속·이속·회피)과 궁합. 초보도 이 계열만 파면 완주 가능한 안정형.

## ③ 사냥 도구 — 떼몰이 광역 (폭발·함정)

```
[Tier 1] ─ Lv1 해금 ──────────────────────────────────
  ⬆ 폭발물 숙련 (수류탄 피해·범위)
       Lv1 피해 +5%·범위 +2%  →  Lv5 피해 +25%·범위 +10%
       ▶ 폭발 계열의 기본기.

  ⬆ 도화선 (폭발물 쿨타임 감소)
       Lv1 -3%  →  Lv3 -9%   (수류탄 등 쿨감)
       ▶ 폭발을 더 자주. 물량 폭증 구간 대비.

[Tier 2] ─ Lv10 해금 ─────────────────────────────────
  🎯 수류탄 (밀집 지점 포물선 폭발)
       개수: Lv1 1개 → Lv4 2개 → Lv8 3개
       Lv2/6: 폭발 범위↑   Lv3: 피해 +15%   Lv9: 중심부 추가 피해
       Lv7: 화염 지대 생성   Lv10: 파편 폭탄
       폭발 피해 = 무기 피해 × 50%,  기본 쿨타임 5초
       ▶ 가장 많이 뭉친 곳을 자동 조준. 물량 정리의 핵심.

  ⬆ 폭발 범위   [선행: 폭발물 숙련 2]
       Lv1 +4%  →  Lv5 +20%
       ▶ 한 번에 더 넓게. 겹친 적을 통째로.

[Tier 3] ─ Lv15 해금 ─────────────────────────────────
  ⬆ 파편 폭발   [선행: 수류탄 2]
       폭발 시 주변으로 파편 화살 생성
       Lv1: 4개 → Lv3: 10개 (주변 적에 추가 피해)
       ▶ 폭발 1회가 2차 피해로. 잡몹 무리에 특효.

  ⬆ 화염 지대   [선행: 수류탄 3]
       폭발 후 바닥에 화염 장판(초당 지속 피해)
       Lv1 지속 2초 → Lv3 지속 4초
       ▶ 적이 지나는 길목을 불바다로. 지역 장악.

[Tier 4] ─ Lv20 해금 ─────────────────────────────────
  ⬆ 다연장   [선행: 폭발 범위 2]
       수류탄 동시 투척 수 +1/Lv (최대 +2)
       ▶ 여러 밀집 지점을 동시에. 광역 폭딜.

  ⬆ 처치 연쇄   [선행: 화염 지대 1]
       폭발로 적 처치 시 작은 2차 폭발
       Lv1 30% → Lv3 60% 확률, 초당 상한 있음
       ▶ 물량이 많을수록 연쇄가 커지는 스노볼.

[Tier 5] ─ Lv25 해금 ─────────────────────────────────
  ⭐ 융단 폭격   [선행: 다연장 or 처치 연쇄]
       일정 시간마다 화면 곳곳에 자동 폭격이 쏟아짐
       (예고 후 착탄, 밀집 지역 초토화)
       ▶ 폭발 빌드의 궁극. 가만히 있어도 사방이 터진다.
```

**사냥 도구 요약**: 지능(스킬 쿨감·범위·지속)과 궁합. 후반 극한 물량에 가장 강한 광역 특화.

## 능력치와의 시너지 (한눈에)

| 계열 | 궁합 능력치 | 정석 빌드 예시 |
|---|---|---|
| ① 정밀 사격 | **힘**(피해·크리피해) | 힘 몰빵 + 연발·치명타 → 보스 원콤 |
| ② 질풍 사냥 | **민첩**(공속·이속·회피) | 민첩 위주 + 다발·난사 → 물량 카이팅 |
| ③ 사냥 도구 | **지능**(쿨감·범위·지속) | 지능 위주 + 수류탄·화염 → 화면 초토화 |
| (공통) | **활력**(체력·회복·부활) | 어느 빌드든 생존 보강 |

## 밸런스 검증 계획

이 수치들이 실제로 균형 잡히는지는 **랩의 자동 시뮬레이터**로 검증한다:
빌드별(정밀/질풍/사냥도구)로 봇을 돌려 생존·클리어율을 비교 → 한 계열이 압도하면 그 노드 수치를 조정.

*(화살 발사 버그 수정으로 시뮬 신뢰도 회복됨 — 이제 빌드 비교에 쓸 수 있다.)*
