## 1. 타이틀 + 로딩 화면

`src/title-screen.js` (DOM 오버레이). 다른 화면(레벨업·룬·결과)이 전부 DOM 이라 방식을 통일했다.

```
로드 중  →  타이틀 + 진행률 막대 (0~100%)
로드 완료 →  "탭하여 시작" 버튼 (맥동)
탭        →  페이드아웃 + 배경음악 재생 + 게임 시작
```

- 게임 이름은 `title-screen.js` 상단 상수 **한 곳**에만 있다:
  `GAME_TITLE = 'GRIMHOLD'` / `GAME_SUBTITLE = '어둠의 사수'` — 바꾸려면 여기만 고치면 된다
- 하단에 조작 안내(이동/공격) + 소리 토글
- 패널 아무 곳이나 탭해도 시작(모바일에서 버튼 정확히 누르기 어렵다) / PC 는 Space·Enter
- 가로 모드 폰 대응 미디어쿼리 포함

### 왜 시작 버튼이 필수인가 (UX가 아니라 기술 제약)
브라우저는 **사용자 제스처 없이 오디오를 재생하지 못한다.** 로드되자마자 게임이
시작되면 배경음악을 영원히 틀 수 없다. 시작 탭이 그 제스처 역할을 한다.

### 재시작 시 타이틀이 다시 뜨지 않게
`gameStarted` 를 **모듈 스코프**에 뒀다. `scene.restart()` 는 `create()` 를 다시
돌리므로 씬 안에 두면 "다시 하기"마다 타이틀이 또 뜬다.

### 대기 중 검은 화면 방지
`update()` 가 대기 중이면 로직은 멈추지만 **한 프레임은 그린다**(`_bootFrame`).
타이틀 뒤로 던전 바닥과 캐릭터가 비쳐서 "준비됐다"는 느낌이 난다.

## 2. 배경음악

`tools/audio/gen_bgm.py` — 파이썬으로 **합성**했다(외부 음원 없음 → 저작권 문제 없음).
32초 심리스 루프, **206KB(ogg)**. 폴백으로 m4a(258KB)도 생성한다.

### 음악 설계
| 레이어 | 역할 |
|---|---|
| 서브 드론 55Hz + 5도 | 곡의 바닥. 헤드폰/PC에서 "무게" |
| 로우 패드 (A 마이너 3화음) | 먼 오르간 같은 화성 |
| **중역 패드 260~1700Hz** | **모바일 스피커에서 실제로 들리는 층** |
| 삐걱임/긁힘 | 중역 던전 질감 |
| 심장박동 (2초마다 쿵-쿵) | 유일한 리듬. 드럼 대신 심장박동 → '전투'보다 '긴장' |
| 공기/바람 | 공간이 비어 보이지 않게 |
| 먼 금속 타격 (3회) | "사람이 없는 곳"이라는 신호 |
| 리버브 | 원형 컨볼루션 |

**멜로디를 거의 넣지 않았다.** 한 판이 길고 곡이 계속 반복되므로 선율이 뚜렷하면
금방 질린다. 드론 + 박동 + 공간감이 주역이다.

### 작업 중 잡은 문제 2가지 (둘 다 실측으로 발견)

**① 모바일에서 안 들릴 상태였다.**
처음 만든 버전은 800Hz 이상 에너지가 **0%**, 스펙트럴 센트로이드 87Hz였다.
폰 스피커는 300Hz 이하를 거의 못 내므로 **무음에 가깝게** 들린다.
원인은 피크 정규화가 55Hz 서브에 잡혀서 나머지 전부가 같이 작아진 것.
→ 서브 게인을 낮추고 중역 레이어를 추가 + 마스터 틸트(120Hz 이하 -4dB).

| | 처음 | 수정 후 |
|---|---|---|
| 20-80Hz | 60% | 19% |
| 300-800Hz | 2.4% | **17%** |
| 폰 스피커 모사(400Hz HPF) | **-33.8 dBFS** (거의 안 들림) | **-27.7 dBFS** |

**② 루프 이음부에 클릭이 남았다.**
원인은 크로스페이드가 아니라 **패드 주파수가 루프 길이의 정수배가 아니었던 것**
(C3 130.81Hz × 32s = 4185.9주기 → 경계에서 위상 불일치).
크로스페이드로 덮으려 했더니 오히려 나빠졌다.
→ 제대로 고친 방법 3가지를 **모두** 적용:
1. 모든 주파수를 `1/32Hz` 격자에 스냅 (`q()`) — 오차 0.016Hz로 음정 차이는 안 들린다
2. 필터를 **원형(circular)** 으로 — FFT 주파수응답 곱셈. 경계에서 필터 상태가 연속
3. 리버브를 **원형 컨볼루션** — 잔향이 루프 앞으로 자동 wrap

검증: `이음부 점프 +0.0130` vs `경계 직전 기울기 +0.0118` — 거의 같으므로 **연속**이다
(불연속이면 점프가 주변 기울기보다 훨씬 커야 한다).

### 재생성
```bash
python3 tools/audio/gen_bgm.py     # numpy, scipy, ffmpeg 필요
```

## 5. 🔴 정리 필요 — `public/` 이 8.83MB인데 실제 로드는 1.0MB

Vite 는 `public/` 을 `dist` 로 **통째 복사**한다. 그래서 생성 스크립트와
미리보기 PNG가 전부 배포된다. 실측:

```
public/ 전체            8.83 MB
게임이 실제 로드          1.04 MB
불필요하게 배포             7.33 MB  ← 8.5배
```
