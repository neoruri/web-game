## 0-a. ✅ 결과 화면 구현 완료 (신규)

`src/result-screen.js` + `result-screen.css` 신규. 기존 게임오버는 캔버스 텍스트 3줄뿐이었다.

- **지표 4칸**: 버틴 시간 · 처치 · 레벨 · 보스. 각 칸마다 **최고 기록 비교**,
  갱신하면 금색 테두리 + "최고 기록!"
- **최종 빌드**: 보유 스킬과 레벨을 칩으로 표시
- **장착한 룬 전체**: 등급색 + 굴려진 수치(등급 높은 순 정렬) → "이번 판 뭘 모았나"가 남는다
- **최고 기록은 localStorage**(`wg_best_v1`)에 저장. 판마다 리셋되는 게임에서 **유일하게 남는 것**
- `n번째 도전` 카운터 → 반복 플레이가 축적된다는 감각
- 사망 애니를 **0.65초 보여준 뒤** 결과 화면을 띄운다

### 함께 고친 버그 2건
1. **결과 화면 전 클릭으로 기록이 유실되던 문제**
   기존 `pointerdown`/`SPACE`가 `gameOver`면 즉시 `scene.restart()`를 했다.
   사망 애니 0.65초 사이에 탭하면 결과 화면을 건너뛰어 **최고 기록이 저장되지 않았다.**
   → `result.isOpen`일 때만 재시작하도록 변경.
2. **재시작마다 오버레이 DOM이 쌓이던 문제**
   `scene.restart()`가 `create()`를 다시 돌리는데 각 오버레이가 `appendChild`만 했다.
   → `levelup-modal` / `rune-modal` / `growth-modal` / `result-modal` 모두
   생성 전 `document.getElementById(id)?.remove()` 추가. **기존에 있던 잠재 누수까지 정리됨.**

## 0. 방금 고친 것 (커밋 대상)

### 🐛 룬 장착 화면에서 스크롤이 안 되는 문제
- **원인**: `style.css`의 `body { touch-action: none }` — 조이스틱 드래그가
  페이지 스크롤로 새지 않게 넣은 설정인데, **오버레이 내부 스크롤까지 막았다.**
  "가끔"이었던 이유는 **가방이 길어져 스크롤이 필요할 때만** 드러나기 때문.
- **수정**: 스크롤 영역에서 되돌림 —
  `.lv-scroll`(레벨업), `.growth-scroll`·`.gv-dock`(성장 화면)에
  `touch-action: pan-y; overscroll-behavior: contain;` 추가.
- ⚠️ 앞으로 **새 오버레이에 스크롤을 넣을 때마다 이 설정을 같이 넣어야 한다.**

## 3. 그다음 — 판 안을 드라마틱하게

### 3-1. 몹 밀도 스파이크 (비용 최저, 효과 큼)
현재 스폰은 완만히 증가만 해서 **쓸어버리는 순간이 없다.**
40초마다 20마리를 한 번에 쏟으면 핵앤슬래시 쾌감이 생긴다. **config 값 조정만.**

### 3-2. 네임드/엘리트 몹 + 접두어
```
화염의(피격 시 화상) · 신속한(이속 1.6배) · 강인한(체력 3배) · 분열하는(죽으면 2마리)
```
- 몹 3종 × 접두어 4종 = 조합 수십 개 → **콘텐츠를 싸게 늘리는 정석**
- 이름표 + 외곽 오라로 "저건 위험하다"를 즉시 읽히게
- 네임드가 **룬 확정 드랍** → 앞서 논의한 엘리트 드랍과 결합
  (일반몹 %드랍은 킬 수 편차가 65배라 실력 격차를 증폭시킨다 — 네임드가 더 공평)

### 3-3. 타격감 강화
처치 이펙트 · 화면 흔들림 · 큰 데미지 숫자 (일부 이미 있음)
