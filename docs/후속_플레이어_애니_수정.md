# 후속 수정 — 위로 이동 시 캐릭터 사라짐 + run 속도

> `docs/커밋요청_플레이어_스프라이트_활.md` 적용 후 나온 두 가지.
> 둘 다 **이미지 재작업 없이 코드만** 고치면 된다.

---

## 1. ★ 위로 이동하면 캐릭터가 사라진다

### 원인
`updatePlayerAnim` 은 위로 갈 때 `back_run` 을 재생한다.

```js
const key = !moving ? 'idle' : vy < -0.35 ? 'back_run' : 'run'   // main.js:1224
```

그런데 **새 시트의 행2(back_run)가 비어 있다.** 시트 실측:

```
행0 idle       4개 [0,1,2,3]
행1 run        6개 [0,1,2,3,4,5]
행2 back_run   0개   ← ★ 비어 있다
행3 attack     0개
행4 multishot  0개
행5 hit        0개
행6 death      0개
```

빈 셀을 그리니 투명해서 안 보인다. **버그가 아니라 없는 그림을 재생 중**이다.

> 앞 문서에서 `death` 만 경고했다. `back_run` 은 **실제로 매번 재생되는데** 놓쳤다.

### 고치기 — 시트가 채워질 때까지 run 으로 대체

`defs` 에서 `back_run` 을 **만들지 않는다.**

```js
const defs = {
  idle: { row: 0, frames: 4, fps: 6, loop: true },
  run: { row: 1, frames: 6, fps: 8, loop: true, order: [0, 2, 3, 5, 3, 2] },
  // back_run / attack / multishot / hit / death 는 시트 행이 비어 있다.
  // 등록하면 빈 셀이 재생돼 캐릭터가 투명해진다. 채워질 때까지 주석 처리한다.
}
```

그리고 선택부에서 `back_run` 을 쓰지 않는다.

```js
// back_run 시트가 없다. 위로 갈 때도 run 을 쓴다.
// 뒷모습이 없을 뿐 어색하지 않다 — 뱀서류에서 흔한 처리다.
const key = !moving ? 'idle' : 'run'
```

`death` 도 마찬가지다. `main.js:2801` 에서 `this.animKey = 'death'` 로 바꾸고
`sp.play('death')` 를 호출한다면 **그 호출을 막아야 한다.** `animKey` 만 바꾸고
애니는 그대로 두면(=run/idle 유지) 최소한 캐릭터가 사라지지는 않는다.

## 2. run 이 너무 빠르다 — 발이 미끄러진다

### 원인
애니 속도가 이동 속도와 안 맞는다. **발 스케이팅**이다.

계산 근거:
```
화면 표시     캐릭터 64px  (셀 116 × scale 0.55)
contact 보폭  셀 90px → 화면 50px
이동 속도     cfg.player.speed = 100 px/s
order 길이 6 = 실제 걸음 2회 (뒤의 3,2 는 되감기)
```

```
 fps   사이클    이동거리   걸음당   보폭 50px 대비
  12   0.50s     50.0px    25.0px    0.51배   ← 지금. 발이 2배 헛돈다
  10   0.60s     60.0px    30.0px    0.61배
   8   0.75s     75.0px    37.5px    0.76배
   6   1.00s    100.0px    50.0px    1.01배   ← 계산상 정확
```

**1.0 에 가까울수록 발이 안 미끄러진다.** 지금 0.51 배라 다리가 실제 이동의
두 배 속도로 움직인다.

### 고치기
```js
run: { row: 1, frames: 6, fps: 8, loop: true, order: [0, 2, 3, 5, 3, 2] },
```

**`fps: 8` 을 먼저 써본다.** 계산상 정확한 값은 6 이지만, 6은 눈에 띄게 느려서
게임이 굼떠 보일 수 있다. 8이 절충점이다. 돌려보고 여전히 빠르면 6, 굼뜨면 10.

> 되감기 구간(뒤의 `3,2`)이 있어서 실제 체감은 계산보다 조금 빠르다.
> 최종 판단은 눈으로 한다.

### 이동 속도가 룬으로 바뀌면
`cfg.player.speed` 는 룬으로 변한다. 정확히 맞추려면 fps 를 속도에 비례시킨다.

```js
// 선택 사항. 이동이 빨라지면 다리도 빨라진다.
const RUN_FPS_BASE = 8, RUN_SPEED_BASE = 100
this.playerSprite.anims.msPerFrame =
  1000 / (RUN_FPS_BASE * (this.stats.player.speed / RUN_SPEED_BASE))
```

지금 단계에선 **고정 8로 두고 넘어가도 된다.** 속도 룬이 붙은 뒤에 보면 된다.

## 3. 확인

```
npm run build
```

1. **위·아래·좌·우로 다 움직여도 캐릭터가 안 사라지는가** ← 이번 핵심
2. 달릴 때 발이 헛돌지 않는가
3. 죽을 때 캐릭터가 사라지지 않는가
4. 활이 계속 등에 붙어 있는가
