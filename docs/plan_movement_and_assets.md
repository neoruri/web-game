## 1. 몬스터 유기적 이동 + 겹침 방지

### 지금 문제

모든 적이 플레이어를 향해 **직진**한다. 그래서 한 점에 뭉치고 서로 완전히 겹쳐서, 수십 마리가 한 마리처럼 보인다. 뱀서류의 "떼로 몰려오는 맛"이 안 산다.

### 방법 3가지

| 방식 | 내용 | 평가 |
|---|---|---|
| **A. 분리력 (Separation)** | 각 적이 가까운 적에게서 살짝 밀려나는 힘을 추격 방향에 더함 | ★ 추천. 뱀서·보이드 표준, 자연스러움 |
| B. 소프트 충돌 | 겹치면 반발 벡터로 밀어냄 | 단순하지만 밀도 높으면 떨림 |
| C. 풀 플로킹 | 분리+정렬+응집으로 무리 이동 | 과함. 뱀서엔 불필요 |

**추천: A (분리력)만 가볍게.** 이미 있는 `grid.js`(공간 분할)로 이웃을 싸게 찾을 수 있어 궁합이 좋다.

### 핵심 로직 (의사 코드)

```
각 적 e:
  chase = (플레이어 - e) 정규화
  sep = 0
  for 이웃 n in grid.query(e, 반경R):   // 근처 셀만
      sep += (e - n) / 거리²           // 가까울수록 강하게 밀림
  이동방향 = chase + sep * 분리강도
```

### 최적화 (적 400+ 기준)

- **그리드 조회**로 전체 쌍 비교(O(n²)) 회피 — 근처 셀만
- **이웃 최대 K개**만 반영 (예: 6마리) — 밀집 지역에서 폭주 방지
- **격프레임 갱신** — 분리 계산을 2~3프레임마다만, 그 사이엔 직전 벡터 재사용
- 예상 부담: 관리 가능. 튜너에 `분리강도`·`반경` 노출해 실시간 조절

### 공수/리스크

- 공수: 반나절. 리스크: 밀집 시 떨림/성능 → K제한·격프레임으로 완화
- 시뮬레이터에도 같은 로직 반영해야 밸런스 실측이 정확

## 2. AI 이미지 에셋 디자인

### 지금 상태

플레이어=원, 적=네모, 젬=작은 사각형. 미니멀하지만 "게임다운" 인상은 약하다.

### AI 생성 워크플로우

1. **스타일 고정** — 탑다운 시점, 통일 팔레트(현재 Catppuccin), 픽셀아트 or 플랫 벡터 중 택1
2. **생성 도구** — Stable Diffusion(로컬·무료), Midjourney(유료·고품질), DALL·E, Bing 이미지
   - 프롬프트 키워드: `top-down game sprite, transparent background, flat, consistent palette`
3. **최소 에셋 목록**
   - 플레이어 1종 (정면 또는 4방향)
   - 적 3종(기본/돌진/탱커) + 보스 1종
   - 젬 · 화살 · 폭발 이펙트
4. **애니메이션(선택)** — 걷기 2~4프레임 스프라이트시트
5. **후처리** — 배경 투명 PNG, 크기 통일(32×32 / 64×64), 압축(TinyPNG)
6. **Phaser 적용** — `load.spritesheet` → `anims.create` → `sprite.play`. 지금의 Graphics 도형 렌더를 스프라이트로 교체

### 주의점

- **저작권** — 상용 게임 캐릭터 복제 금지(스펙 명시). AI 프롬프트에도 특정 IP 넣지 않기. 오리지널 스타일로.
- **성능(20MB·로딩 3초)** — 스프라이트를 **텍스처 아틀라스 하나**로 묶어 드로우콜을 배칭. 수백 마리는 사실 도형이 더 가볍다 — 스프라이트로 가면 텍스처 배칭이 필수
- **일관성** — AI는 매번 스타일이 흔들림. 시드 고정 + 같은 프롬프트 베이스 + 사후 색보정
- **무료 대안** — [Kenney.nl](https://kenney.nl) CC0 게임 에셋. AI 없이 즉시 통일된 세트. 빠른 검증엔 오히려 유리

### PM 관점 — 우선순위 경고

지금은 **아직 5명 재미 검증 전**이다. 도형으로 "재밌는지"부터 확인하고, 재미가 확인된 **뒤에** 에셋에 투자하는 게 순서다. (기획서의 "예쁜 쓰레기 경계" 원칙)

에셋은 **완성도/포털 심사 단계**의 일이다. 지금 우선순위가 높은 건 게임플레이(이동·겹침·스킬 밸런스)다.
