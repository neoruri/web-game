# 현재 스킬·룬 시스템 상태 (일반 채팅 공유용)

> **용도**: 코드 작업 채팅과 별개인 "기획·논의용 일반 채팅"에 이 내용을 통째로 붙여넣으면,
> 지금 게임에 **실제로 적용돼 있는** 스킬·룬 구조를 알고 이어서 논의할 수 있다.
> 갱신일: 2026-08-05 · 게임: Phaser 3 뱀서류 · 배포 https://web-game-tau-sable.vercel.app

---

## 0. 큰 그림 — 성장 구조가 "카드 + 룬"으로 피벗됨

기존엔 **스킬트리(힘/민첩/지능/활력 능력치 찍기)** 성장 화면을 만들고 있었으나,
뱀서(Vampire Survivors) 표준에 맞춰 **레벨업 3택 카드 + 보스 룬**으로 방향 전환했다.

- **능력치 스킬트리 화면 = 보류** (코드는 남겨둠, 진입 버튼 숨김, attr=0으로 고정)
- 지금 살아있는 성장 = 아래 두 축뿐:
  1. **레벨업 → 3장 카드 중 1택** (판 안에서 계속)
  2. **보스 처치 → 룬 드랍 → 스킬에 장착**

---

## 1. 레벨업 카드 (경험치 차서 레벨업할 때마다)

레벨업하면 게임이 멈추고 **카드 3장** 제시 → 1장 선택. 카드는 두 종류가 섞여 나온다.

### A. 스킬 카드 (4종 액티브 스킬)
| 스킬 | 아이콘 | 효과 |
|---|---|---|
| 다발 사격 (multishot) | 🏹 | 가까운 적 방향으로 부채꼴 연사 |
| 연발 사격 (rapidfire) | 💥 | 가까운 적을 단일 집중 연사 |
| 난사 (barrage) | 🌪️ | 이동하며 주변 360° 난사 |
| 수류탄 (grenade) | 💣 | 밀집 지점에 던져 범위 폭발 |

- 처음 뽑으면 **해금(Lv1)**, 이미 있으면 **레벨업(Lv n→n+1)**.
- **동시 보유 가능한 액티브 = 최대 5개** (`MAX_ACTIVE=5` = 기본 사격 + 액티브 4종 전부).
  즉 사실상 4종을 다 켤 수 있음.

### B. 패시브 카드 (4종, 중첩 누적)
| 패시브 | 1스텝 효과 |
|---|---|
| 데미지 ⚔️ | 모든 피해 +10% |
| 이동속도 👟 | +8% |
| 최대체력 ❤️ | +15% |
| 공격속도 ⏱️ | 기본·스킬 쿨타임 감소 +8% |

- 같은 패시브를 또 뽑으면 계속 누적(스택). 현재 스택은 카드에 "(현재 +xx%)"로 표시.

---

## 2. 룬 (보스 처치 보상)

보스를 잡으면 **룬 1개 획득** → 화면에서 **룬 3종 중 1택** → 이어서 **어느 스킬에 끼울지** 선택.
룬은 **스킬 슬롯당 1개** (기본 사격에도 낄 수 있음). 다시 장착하면 교체.

### 룬 5종
| 룬 | 아이콘 | 효과 (장착한 그 스킬에만 적용) |
|---|---|---|
| 데미지 | ⚔️ | 그 스킬 피해 +20% |
| 관통 | ➹ | 그 스킬 관통 +1 |
| 발사체 | 🎯 | 그 스킬 발사체/투사 수 +1 |
| 쿨감 | ⏱️ | 그 스킬 쿨타임 -15% |
| 화상 | 🔥 | 명중 시 3초간 도트(지속) 피해 |

- **화상 도트** = 명중 피해의 30%/초, 3초 지속. 불붙은 적은 주황색으로 타오르고,
  도트만으로도 죽을 수 있음(사망 처리 공유).
- 룬 선택 화면은 3개 랜덤 노출(5종 풀에서).

---

## 3. 카드 vs 룬 — 역할 구분 (설계 의도)

- **카드** = 판마다 리셋되는 **일반적 성장** (스킬 해금·레벨, 전반적 스탯 상승). 넓고 얕게.
- **룬** = 보스라는 **관문 보상**, 특정 스킬을 **뾰족하게 특화**. 좁고 깊게.
- 그래서 카드는 "전체 데미지 +10%", 룬은 "이 수류탄만 화상" 식으로 성격이 갈린다.

---

## 4. 지금까지 완료된 단계 (MVP 기준)

- ✅ **1단계** — 레벨업 3택 카드 (스킬 해금/레벨 + 패시브 4종)
- ✅ **2a** — 보스 룬 드랍 + 스킬에 장착 (데미지/관통/발사체/쿨감 4종)
- ✅ **2b** — 화상 룬 추가 (도트 피해) → **룬 5종 완성**
- ✅ 보스가 안 나타나던 버그 수정 (보스는 화면 밖으로 사라지지 않게)
- **→ 룬 MVP 완료. 현재 폰에서 재미·밸런스 확인 대기 중.**

---

## 5. 아직 안 한 것 / 다음 후보 (논의 대상)

여기가 **일반 채팅에서 같이 정하면 좋은 부분**:

- **밸런스** — 카드 확률, 룬 수치(+20%/+1이 적정?), 보스 주기(현재 90초), 화상 30%/3초 등
- **3단계 후보** (룬 기획서에 있음):
  - 슬롯 확장 — 스킬당 룬 1개 → 레벨로 2칸
  - 룬 티어 — 같은 룬도 등급(강도) 차이
  - 룬 콤보 — 특정 조합 시 추가 효과
- **재미 요소** — 스킬 4종만으로 충분한가? 신규 스킬/무기 추가?
- **컨텐츠 지속성** — 스테이지/난이도 곡선, 목표(보스 처치 수 등)

## 6. 참고 (코드 채팅 쪽 사실)

일반 채팅에서 "이렇게 바꾸자"가 정해지면, 코드 채팅에 그 결론을 붙여넣으면 반영 가능.
반대로 코드가 바뀌면 이 문서를 갱신해 다시 일반 채팅에 붙여넣는 식.

- 원본 룬 기획: `docs/rune_system/RUNE_MVP_컴팩트기획.md`
- 실제 계산 로직: `src/progression.js` 의 `deriveStats()` (수치 바뀌면 여기서 계산됨)
- 게임/시뮬 동기화됨: `src/main.js` ↔ `src/sim.js` (밸런스 검증은 헤드리스 시뮬로 가능)
