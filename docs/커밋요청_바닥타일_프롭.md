> 코덱스(코드 채팅)용 작업 지시서. **이 문서만 보고 끝까지 진행할 수 있게** 썼다.
> 배경 설명이 필요하면 `변경내역_바닥타일_D15.md`, `변경내역_프롭_AI스프라이트.md` 참고.

## ⚠️ 먼저 읽을 것 — 이 변경에서 `npm run build` 는 검증력이 거의 없다

Vite 는 `public/` 을 `dist` 로 **그대로 복사**한다. PNG 를 파싱하지도, 규격을 확인하지도
않는다. 코드 변경이 0 이므로 빌드는 무조건 통과한다.
→ 빌드는 "깨지지 않았다"는 최소 확인일 뿐이고, **아래 STEP 1·2 가 실제 검증이다.**

## STEP 1 — 에셋 규격 자동 검증 (실제 검증 ①)

```bash
python3 tools/sprites/apply_props_n3.py
```

`public/sprites/dungeon/props_iso.png` 을 **재생성하고 7항목을 assert** 한다.
멱등이므로 지금 파일과 같은 결과가 나와야 한다. 아래가 그대로 출력되면 통과:

```
✅ 시트 크기 768×112
✅ 8칸 전부 폭이 셀 안에 있다 (53/54/77/43/61/81/29/66)
✅ 8칸 모두 하단 y=111
✅ 횃불 화로 접지선 기준 77px 위 (코드 기대 76px, 허용 ±6)
✅ 마젠타 프린지 0px
✅ 바닥과 명도차 15.5 (허용 15~32)
✅ 색조가 바닥과 6 이내
전부 통과 — main.js 수정 불필요
```

❌ 가 하나라도 나오면 **커밋하지 말고 보고**할 것.
(numpy / Pillow 필요. 없으면 `pip install numpy pillow`)

## STEP 2 — 브라우저 육안 확인 (실제 검증 ②)

```bash
npm run dev      # http://localhost:5173/
```

볼 것 — 이 5개가 이번 변경에서 깨질 수 있는 전부다:

1. **프롭이 바닥에 붙어 있는지** — 공중에 뜨거나 파묻히면 접지선 정렬 실패
2. **횃불 불꽃이 화로 그릇에서 피어나는지** — 떠 있으면 화로 높이 어긋남
   (불꽃은 스프라이트가 아니라 `main.js` 의 `gfxFlames` 가 그린다)
3. **바닥이 너무 어둡지 않은지** — 적·화살·이펙트가 다 얹힌 상태에서 판단
4. **적 스프라이트가 바닥에 묻히지 않는지** — 특히 고블린
5. **난사 민트색(`#a6e3a1`)·독 초록(`#9ae86a`) 이 초록 바닥과 겹쳐 안 보이지 않는지**
   ← 새 바닥이 초록 계열이라 생긴 신규 리스크. 이번에 처음 확인하는 항목이다.

## STEP 4 — `.gitignore` 추가 (⚠️ 커밋 전 필수)

`tools/sprites/` 에 미리보기·후보 PNG 가 **15MB** 쌓여 있다. 전부 스크립트로
재생성 가능한 파일인데, gitignore 대상이 아니라서 `git add .` 하면 히스토리에 영구히 박힌다.
(기존 `.gitignore` 는 `public/sprites/**/_*.png` 만 막고 `tools/` 는 안 막는다.)

`.gitignore` 맨 끝에 추가:

```
# 스프라이트 생성 중간 산출물 (미리보기·후보 — 15MB, 스크립트로 재생성 가능)
tools/sprites/_*.png
tools/sprites/tileset_iso_dark_*.png
tools/sprites/tileset_iso_gemini_*.png
tools/sprites/props_iso_N*.png
tools/sprites/props_iso_P*.png
```

이러면 신규 커밋 대상이 15MB → **3.4MB** 로 줄어든다.
대부분 AI 원본 2장(1.3MB + 2.1MB)이며, 이건 **남겨야 한다** — apply 스크립트가 읽고,
Poki 가 "어떤 툴·프롬프트를 썼는지 제출"을 요구한다(`프롭_AI생성_프롬프트.md` §7).

## 덤으로 부탁 — 방치 파일 정리 (별도 커밋)

`public/` 아래 파일은 Vite 가 `dist` 로 통째로 복사하므로 **전부 배포된다.**
gitignore 는 이미 추적된 파일을 빼주지 않으므로 `git rm --cached` 가 필요하다.

```bash
git rm --cached public/sprites/dungeon/tileset_iso_stone_OLD.png
rm public/sprites/dungeon/tileset_iso_stone_OLD.png     # 104KB
```
