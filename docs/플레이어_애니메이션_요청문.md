## 0-a. ⚠️ 이 문서를 AI 에 그대로 주지 말 것

이 파일은 **사람이 보는 작업 지시서**다. 통째로 넘기면 한국어 해설·첨부 지시가 섞여
"무엇을 그릴지"가 모호해진다(디자인 시안 단계에서 실제로 겪었다).

**요청 하나당 메시지 하나.** 해당 코드블록만 복사해 붙이고, 지정된 이미지를 첨부한다.

### 매 장 받고 바로 확인할 4가지

1. **프레임 수**가 맞는가 (요청한 수와 같은지 눈으로 셈)
2. **발끝이 한 줄에** 놓였는가 — 이게 가장 중요하다 (idle 은 편차 0px 로 나왔다)
3. **연기가 없는가** — 있으면 재생성 (코드가 그린다)
4. **배경이 순수 초록**인가

> 결과가 점점 어긋나기 시작하면 **새 대화를 열고 C3 를 다시 첨부**해서 이어가면 된다.
> 밑단 발광은 안 나와도 괜찮다 — 내가 후처리로 자동 보정한다.

## 0. 요청 전 반드시 확인할 것 4가지

### ① 배경은 **초록 `#00FF00`** — 마젠타 아님

이전 문서들에는 마젠타 `#FF00FF` 로 적혀 있는데, **이 캐릭터에는 쓸 수 없다.**
발광색이 자마젠타(292도)라서 배경을 빼면 **발광까지 같이 지워진다.**

초록이 안전한 이유: 몸통은 **채도가 낮은** 회녹색이고(순수 초록과 거리가 멀다),
발광은 마젠타로 **색조가 정반대**다. 캐릭터 어디에도 채도 높은 초록이 없다.

### ② 연기 오라는 **그리지 않는다**

디자인 시안에는 있지만 애니메이션 시트에는 **넣지 않는다.**
연기는 게임이 코드로 그린다(`gfxFlames` 가 횃불 불꽃을 그리는 것과 같은 방식).
이유 3가지는 `캐릭터_디자인샘플_프롬프트.md` §5-b — 요약하면
**굽힌 연기는 얼어붙고, 64px 에서 실루엣을 먹고, 이미 같은 선례가 있다.**

### ③ 망토 밑단 발광은 **꼭 넣는다**

C3 시안을 세로 5구간으로 재보니 발광이 상체에만 몰려 있었다:

```
머리·후드 9.3% / 어깨·가슴 16.9% / 허리·손 15.9% / 허벅지 0.9% / 밑단·부츠 0.4%
```

미관 문제가 아니다. 발광이 위로만 쏠리면 **실루엣의 읽는 지점이 상체에 몰려**
어두운 바닥 위에서 하단 경계가 사라진다. 밑단이 빛나야 발밑이 잡히고 접지감이 산다.
→ 모든 프롬프트에 독립 항목으로 강하게 넣었다.

### ④ 기준 이미지를 **매번 첨부**한다

43프레임이 같은 캐릭터여야 하는 것이 이 작업의 전부다.
확정된 C3 이미지를 매 요청에 첨부한다. 가능하면 **같은 대화에서 이어서** 요청한다.

## 2. 공통 규칙 (모든 프롬프트에 이미 포함돼 있음 — 참고용)

- 측면 **우향**. `setFlipX` 로 좌향을 만든다 → 정면·후면 금지 (back_run 만 예외)
- **모든 프레임에서 발끝이 같은 높이** (내가 y=108 로 재정렬하지만 원본이 맞아야 품질이 좋다)
- 프레임 간 **가로 중심 ±3px** — 지금 시트는 run 이 7.4px 흔들려 좌우로 떨린다
- 외곽선·림·발광 테두리 **금지** — 코드가 `postFX.addGlow` 로 붙인다
- 바닥 그림자 **금지** — 게임이 따로 그린다
- **국소 대비 유지** — 명도 단계 5~6개를 넓게 벌린다. 64px 로 줄면 중간톤은 사라진다
