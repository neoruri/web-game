# 재플레이 요소 설계 분석 — 뱀서 로그라이크 + 디아블로 핵앤슬래시

> 작성: 2026-08-07 · 목표: "다시 하고 싶다"를 만드는 컨텐츠 방향 결정
> 현 상태 진단: **전투는 되지만 루프가 없다.** 죽으면 전부 리셋되고, 해금되는 것도,
> 남는 것도, 다음에 다르게 해볼 이유도 없다. 그래서 재미가 없는 게 정상이다.

---

## 1. 두 게임의 훅은 서로 다르다 (먼저 구분할 것)

| | 뱀서류 | 디아블로(핵앤슬래시) |
|---|---|---|
| 한 판의 재미 | **판 안에서 빌드 완성** — 약→강 변신 | 몹 무리 쓸어버리는 **타격 쾌감** |
| 다시 하는 이유 | **언락**(새 캐릭·무기·스테이지) | **아이템 드랍 도박** — 더 좋은 게 나올까 |
| 성장 지속성 | 판마다 리셋 + 영구 골드 | **아이템이 영구히 남음** |
| 핵심 감정 | "이번엔 이 조합" | "이번엔 좋은 게 나왔나" |

즉 **디아블로 느낌의 본질은 그래픽이 아니라 "드랍 → 비교 → 갈아입기" 루프**다.
그래픽만 어둡게 해도 디아블로 느낌은 안 난다. **파밍 대상**이 있어야 한다.

---

## 2. 결정적 발견 — 이미 그 그릇을 만들어 놨다

**룬이 곧 디아블로의 아이템 역할을 할 수 있다.** 새 시스템을 만들 필요가 없다.
지금 룬은 "고정 수치 5종"인데, 여기에 디아블로식 성질 3개만 얹으면 파밍 루프가 생긴다:

1. **등급** — 일반 / 레어 / 에픽 (테두리 색 + 수치 차이)
2. **랜덤 롤** — 같은 룬이라도 수치가 매번 다름
   `화상: 25~35%/초` → "이번 화상은 34%다!" 하는 순간이 생긴다
3. **영구 보관 + 지참** — 판이 끝나도 룬 금고에 남고, 다음 판 시작 시 **1개 지참**

3번이 핵심이다. 이것만으로 **"좋은 룬을 파밍한다"는 동기**가 생기고,
동시에 §3의 "메타 성장"까지 해결된다. 룬 하나로 두 문제를 잡는다.

> 참고: `룬_확장_설계분석.md`에서 "병합은 드랍이 적어 불가"라고 결론냈는데,
> **영구 보관을 도입하면 그 결론이 바뀐다**(여러 판에 걸쳐 모이므로). 순서상 이 결정이 먼저다.

## 3. "다시 하고 싶다"의 3대 원천 — 현재 0개

재플레이는 **"다음엔 ~해보고 싶다"** 는 문장이 생겨야 발생한다. 그 원천은 셋뿐이다.

| 원천 | 지금 | 설명 |
|---|---|---|
| ① **미해금 콘텐츠** | ❌ 없음 | "다음엔 저 캐릭터/무기 써보자" — 목표 제시 |
| ② **영구 성장** | ❌ 없음 | "지난 판이 헛되지 않았다" — 실패 위로 |
| ③ **빌드 실험** | ⚠️ 약함 | "다음엔 화상 몰빵" — 다양성 |

**뱀서류 재플레이의 80%는 ①+②에서 온다.** 스킬 수를 늘리는 것보다 훨씬 효율적이다.
지금은 죽으면 아무것도 안 남고 해금도 없어서, 두 번째 판을 켤 이유가 구조적으로 없다.

## 4. 디아블로 느낌을 만드는 구체 장치

효과/비용 순으로 정렬. ★ = 추천

| 장치 | 디아블로다움 | 비용 | 비고 |
|---|---|---|---|
| ★ **네임드/엘리트 몹 + 접두어** | ★★★ | 중 | "화염의 고블린 대장" — 접두어 조합으로 무한 변형 |
| ★ **룬 등급 + 랜덤 롤** | ★★★ | 중 | §2. 파밍 루프의 핵심 |
| ★ **영구 룬 금고 + 지참** | ★★★ | 낮 | localStorage. 메타 성장 동시 해결 |
| **층(스테이지) 진행** | ★★ | 중 | "던전 3층 도달" — 목표감·난이도 곡선 |
| **보물방 / 제단(선택 위험)** | ★★ | 중 | "위험을 감수하면 보상" — 능동적 결정 |
| 몹 밀도 폭발 구간 | ★★★ | **낮** | 30초마다 대량 스폰 → 쓸어버리는 쾌감. 값만 조정 |
| 타격감 강화(숫자·흔들림·처치 이펙트) | ★★ | 낮 | 일부 이미 있음. 핵앤슬래시 체감 직결 |
| 신규 스킬/캐릭터 | ★ | **높** | 가장 비싸다. 나중 |

### 몹 밀도 폭발이 의외로 가장 값싸다
현재 스폰은 완만하게 증가할 뿐이라 **"쓸어버리는 순간"이 없다.**
`spawn` 값에 **주기적 스파이크**(예: 40초마다 20마리 한 번에)만 넣어도
핵앤슬래시의 쾌감이 생긴다. 코드 변경은 거의 없다.

### 네임드 몹 접두어 = 디아블로 매직 몬스터
```
접두어(체력·속도·능력) × 기본 몹 = 무한 변형
  화염의(피격 시 화상) · 신속한(이속 1.6배) · 강인한(체력 3배)
  분열하는(죽으면 2마리) · 저주받은(플레이어 쿨감 감소)
```
- 몹 3종만으로도 조합이 수십 개 → **콘텐츠 양을 싸게 늘리는 정석**
- 시각적으로 **이름표 + 외곽 오라**를 붙이면 즉시 "저건 위험하다"가 읽힌다
- 앞서 논의한 **엘리트 드랍**과 자연스럽게 결합(네임드가 룬 확정 드랍)

## 5. ⚠️ 경고 — 밸런스가 이미 칼날 위다

`밸런스_시뮬_리포트.md` 참고: 난사 조준 하나 고쳤을 때 **생존이 6배** 변했다.
여기에 영구 성장을 얹으면 파워 인플레가 통제 불가능해진다.

**영구 성장은 "약하게, 넓게"** 가야 한다.
- 나쁨: 영구 데미지 +50% (한 번에 붕괴)
- 좋음: 영구 최대체력 +2%씩 최대 20단계 / 시작 골드 / 룬 1개 지참
- 지참 룬도 **1개 제한**이 안전. 3개 지참은 초반이 너무 쉬워진다.

## 6. 권장 순서 (비용 대비 효과)

### 1단계 — "한 판 더"를 만든다 (가장 값싸고 효과 큼)
1. **결과 화면** — 생존시간·킬·레벨·획득 룬 요약 + **최고 기록**. 지금 없다.
2. **영구 룬 금고** — 획득한 룬이 판 종료 후에도 남는다(localStorage)
3. **다음 판 지참 1개** — 이게 "파밍 → 활용" 루프를 완성한다
4. **간단한 언락** — 누적 킬 500 → 신규 룬 해금, 보스 3킬 → 신규 스킬 해금 등

> 여기까지만 해도 재플레이 동기가 0 → 상당 수준으로 올라간다. 코드 비용은 낮다.

### 2단계 — 판 안을 드라마틱하게
5. **몹 밀도 스파이크** (값 조정만)
6. **네임드/엘리트 몹 + 접두어 3~4종** (룬 확정 드랍)
7. **타격감 강화** — 처치 이펙트, 화면 흔들림, 큰 데미지 숫자

### 3단계 — 파밍 깊이
8. **룬 등급 + 랜덤 롤** (§2)
9. **층 진행 / 보물방·제단**

### 4단계
10. 신규 스킬·캐릭터(가장 비싸므로 마지막)

---

## 7. 지금 가장 급한 한 가지를 꼽으면

**결과 화면 + 영구 룬 금고 + 지참 1개.**

이유: 현재 죽으면 화면이 그냥 리셋되어 **한 판의 성과가 어디에도 기록되지 않는다.**
"내가 뭘 했는지"와 "무엇이 남았는지"를 보여주는 것만으로 재플레이 동기가 생긴다.
스킬을 하나 더 만드는 것보다 10배 효율적이다.

## 8. 다음에 정할 것 (결정 필요)
- 룬을 **영구 보관**할 것인가? (Yes → 파밍 루프 + 병합 가능 / No → 판마다 리셋 유지)
- 지참 룬 개수 (권장 1개)
- 언락 조건을 무엇에 걸까 (누적 킬 / 보스 킬 / 최고 생존시간)
- 층 진행을 넣을까, 무한 생존을 유지할까
