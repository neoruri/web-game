# 룬 확장 설계 분석 — 병합(중복 업그레이드) vs 희귀 등급

> 분석일: 2026-08-07 · 근거: `sim.js` 150판 실행 + 확률 계산
> 질문: ① 룬 종류 추가 ② 레벨로 슬롯 해금 ③ 중복 업그레이드 — 이 중
> **"업그레이드 없이 희귀 등급으로 가는 게 나을까?"**

---

## 1. 결론부터

**희귀 등급을 먼저 하세요. 중복 병합은 지금 구조에서는 작동하지 않습니다.**

이유는 하나입니다 — **한 판에 룬을 평균 0.91개밖에 못 얻습니다.**

| 한 판당 보스 처치(=룬 획득) | 비율 |
|---|---|
| **0개** | **42%** |
| 1개 | 27% |
| 2개 | 30% |
| 3개 | 1% |

병합은 **같은 룬 2개**가 필요한데, 한 판에 1개도 못 얻는 판이 42%입니다.
"발사체 +1 두 개를 모아 +2로" 는 **한 판 안에서 거의 불가능**합니다.

---

## 2. 왜 병합이 안 되는가 (수치)

같은 룬 2개가 모일 확률(랜덤 드랍 가정):

| 획득 수 | 룬 5종 | 룬 10종 |
|---|---|---|
| 2개 | 20% | 10% |
| 3개 | 52% | 28% |
| **4개** | 81% | 50% |
| 6개 | 100% | 85% |

- 병합이 재미있으려면 **한 판에 4개 이상** 얻어야 한다(그래야 짝이 자주 생김).
- 그런데 현재는 0.91개. **4배 이상 늘려야** 병합 시스템이 성립한다.
- 게다가 룬 종류를 늘리면(5종→10종) 짝 확률이 **절반으로** 떨어져
  "룬 종류 추가"와 "중복 병합"은 **서로 상충**한다.

### 결정적 분기 — 룬이 판마다 리셋되는가?
현재 코드는 `runeSlots`가 **판마다 초기화**된다(로그라이크).
- **판마다 리셋(현재)** → 획득 0.91개 → **병합 불가.** 희귀 등급만이 답.
- **영구 보관(메타 성장)** → 여러 판에 걸쳐 모임 → 병합 가능.
  단, 뱀서류의 "판마다 리셋" 성격이 바뀌고 **영구 파워 인플레** 관리가 필요해진다.

> 병합을 하고 싶다면 먼저 이 질문에 답해야 한다. 지금 성격을 유지할 거면 병합은 접는 게 맞다.

---

## 3. 두 방식 비교

| | 희귀 등급 (Normal/Rare/Epic) | 중복 병합 (1+1=2) |
|---|---|---|
| 필요 드랍 수 | **1개로도 성립** | 최소 4개+/판 |
| 즉시 만족감 | **높음** — 등급이 바로 보임 | 낮음 — 짝 모을 때까지 약함 |
| 룬 종류 추가와 궁합 | **좋음**(무관) | **나쁨**(짝 확률 급감) |
| 중복 처리 | 중복은 여전히 무의미 | **중복이 가치를 가짐** |
| 추가 UI | 없음(테두리 색 + 숫자) | 병합 화면·규칙 필요 |
| 구현 난이도 | **낮음** — `tier` 필드 하나 | 중간 |
| 보스 차별화 | 쉬움(상위 보스=상위 등급) | 어려움 |

**희귀 등급이 현재 구조에 압도적으로 유리합니다.**

---

## 4. 그래도 "중복이 아깝다"면 — 제3안 (권장)

병합 화면을 만들지 말고, **이미 그 룬이 있는 스킬에 같은 룬을 넣으면 레벨이 오르게** 하세요.

```
난사에 [화상] 장착중 → 또 [화상] 획득 → 난사에 넣으면 [화상 Lv2]
```

- 별도 병합 UI **불필요** (지금 "어느 스킬에?" 화면 그대로)
- 슬롯 1개여도 **수직 성장 경로**가 생긴다
- 짝을 모을 필요 없음 → **드랍이 적어도 성립**
- 중복이 낭비가 아니게 됨 (병합의 장점만 취함)
- 희귀 등급과 **동시 사용 가능**: `화상 Rare Lv2`

> 실질적으로 "병합"의 이점을 UI 비용 없이 얻는 방법입니다.

---

## 5. ⚠️ 가장 큰 리스크 — 파워 곱셈

계획한 세 가지가 **모두 곱해집니다**:

```
슬롯 수(1→3) × 등급(1→3배) × 병합/레벨(1→3배) = 최대 27배
```

여기에 룬 종류 추가까지 겹치면 밸런스가 무너집니다.
`밸런스_시뮬_리포트.md`에서 이미 확인된 대로 이 게임은 **칼날 위 밸런스**입니다
(난사 조준 하나 고쳤을 때 생존이 6배 변동).

**권장: 세 축 중 둘만 쓰세요.**
- **추천 조합**: 슬롯 해금 + 희귀 등급 (병합은 §4의 레벨 방식으로 대체하거나 생략)
- 세 개를 다 넣으려면 각 축의 배율을 낮추고 **캡**을 걸어야 함
  (예: 등급 배율 1 / 1.5 / 2배, 룬 레벨 최대 2)

---

## 6. 슬롯 해금 — 무엇에 연동할까

계획한 "특정 레벨 이후 자동 해금"은 좋습니다. 잠긴 슬롯을 **보이게 두는 것**도 목표감을 주니 유지하세요.

다만 **플레이어 레벨보다 "그 스킬의 레벨"에 연동하는 걸 권합니다.**

| 연동 대상 | 장점 | 단점 |
|---|---|---|
| 플레이어 레벨 (Lv10 등) | 단순, 예측 가능 | 모든 스킬이 동시에 열려 선택이 없다 |
| **그 스킬의 카드 레벨** | **레벨업 카드가 "어디에 룬을 몰아줄지" 결정** → 두 시스템이 맞물림 | 약간 복잡 |

예: 스킬 Lv4 → 2번째 슬롯, Lv8 → 3번째 슬롯.
그러면 "다발 사격에 집중 투자" 카드 선택이 곧 룬 빌드 결정이 되어,
앞서 지적한 *"룬이 생기면 카드 선택이 약해진다"* 문제도 같이 해결됩니다.

---

## 7. 선행 과제 (이게 더 급함)

**룬 획득량 자체가 너무 적습니다.** 42%의 판에서 룬을 하나도 못 봅니다.
확장을 논하기 전에 이걸 먼저 고쳐야 합니다.

- `boss.everySec` 90 → **60**, 또는 **첫 보스만 45초**로 앞당기기
- 목표: **한 판 3~5개 획득** (그러면 병합도 선택지에 들어옴 — §2 표 참고)
- 이 값을 바꾸면 §2의 결론이 달라질 수 있으니, **드랍 수를 먼저 정하고 병합 여부를 결정**할 것

---

## 8. 권장 순서

1. **보스 주기 조정** → 한 판 3~5 룬 확보 (선행)
2. **희귀 등급 도입** (Normal/Rare/Epic, 배율 1 / 1.5 / 2배 정도로 보수적으로)
   - 상위 보스가 상위 등급을 더 자주 드랍
   - UI는 테두리 색 + 숫자만. 추가 화면 없음
3. **슬롯 해금** (그 스킬의 카드 레벨 4 / 8에 2·3번째 슬롯)
4. **룬 종류 추가** (5 → 8~10종). 이때 §2대로 짝 확률이 떨어지니 병합은 더 불리해짐
5. (선택) **중복 = 룬 레벨업**(§4). 별도 UI 없이 중복 낭비만 해결
6. 병합 전용 시스템은 **룬을 영구 보관하기로 결정한 뒤에만** 검토
