# 캐릭터 재설계 — Gemini 시안 생성

> `docs/캐릭터_재설계_SD.md` 와 **같은 4안**을 Gemini(나노바나나)로 뽑는 문서다.
> 판정 기준·바꾸지 말 값은 그 문서와 동일하다. 여기엔 프롬프트만 있다.

---

## 0. 진행 순서 — 4개를 다 돌리지 않는다

```
1. Gemini 새 대화 → N2_scout.txt 내용 전체를 한 메시지로 (첨부 없음)
                  → cands/gem_N2_a.png
2. 같은 대화에서 "another version, same rules"
                  → cands/gem_N2_b.png
3. ★ 새 대화를 연다 → N3_spellweaver.txt
                  → cands/gem_N3_a.png, gem_N3_b.png
4. 4장을 §3 기준으로 판정 + 게임 크기 53×64 로 확인
5. 쓸 만한 게 있으면 확정 → idle 부터 시작
   둘 다 아니면 그때 N1·N4 를 돌린다
```

**왜 N2·N3 만 먼저인가** — N2 는 케이프가 없어 다리가 가장 잘 보이고(애니 성공률 최고),
N3 는 마법 느낌이 가장 강하다. 둘이 **인상의 양 극단**이다.
N1 은 N2 와 비슷하고 N4 는 그 중간이라, 극단 둘을 먼저 보면 방향이 정해진다.
Gemini 무료 티어가 429 로 막히는 것도 고려한 순서다.

**★ 3번에서 반드시 새 대화를 열 것.** 같은 대화에서 이어 요청하면 앞의 디자인을
물려받는다. 예전에 run 을 4+4 로 나눠 요청했다가 **후반부가 전반부와 실루엣 차이
0.1~1.5% 로 사실상 동일하게** 나온 적이 있다.

## 1. 쓰는 법

`docs/요청문_캐릭터재설계/` 에 txt 4개가 있다. **하나가 메시지 하나**다.

```
N1_shortcape.txt      A안 — 짧은 마법 케이프
N2_scout.txt          B안 — 경장 주문척후병
N3_spellweaver.txt    C안 — 룬각인 주문궁수 (소매 룬 문자)
N4_heavy.txt          D안 — 룬각인 중갑 사수
```

- **첨부 없이** 그냥 내용만 보낸다. 기존 C3 를 붙이면 모델이 **자세와 긴 망토까지
  유지**해버린다 (실제로 겪었다). 이번엔 디자인을 새로 뽑는 거라 첨부가 방해가 된다.
- 한 안당 **2~3번** 돌려서 여러 장 받는다. Gemini 는 시드 고정이 없어 매번 다르다.
- 결과는 `tools/sprites/cands/gem_N1_a.png` 처럼 저장한다.

> ⚠️ **문서를 통째로 붙여넣지 말 것.** 예전에 `{{ACCENT}}` 가 안 치환된 상태로
> 넘겨서 "요청 내용이 비어 있다"는 답을 받았다. **txt 하나 = 메시지 하나**다.

## 1. Gemini 는 SD 와 프롬프트 방식이 다르다

| | SD(Forge) | Gemini |
|---|---|---|
| 문체 | 쉼표로 나열한 태그 | **문장으로 지시** |
| 부정 | Negative 칸이 따로 있음 | **본문에 "DO NOT" 로 적어야 함** |
| 강조 | `(word:1.4)` 가중치 | 대문자 + 반복 |
| 배경 | 프롬프트로 유도 | 명시하면 잘 지킨다 |

그래서 SD 프롬프트를 그대로 주면 안 된다. 아래 txt 는 Gemini 문체로 다시 썼다.

## 2. 4안 공통으로 들어간 것

모든 txt 에 아래가 들어 있다. **이 문구들을 지우지 말 것.**

```
LEGS FULLY VISIBLE            ← 13번 실패의 원인. 이번 재설계의 전부다
bow held LOWERED, pointing down  ← 앞으로 뻗으면 팔이 스윙 못 한다
flat pure green background       ← 마젠타는 못 쓴다. 캐릭터 발광이 자마젠타다
no ground line, no shadow        ← no floor 를 써도 매번 그려온다. 조립이 자동 제거하지만
                                    처음부터 없는 게 낫다
strict side view, facing right   ← 3/4 뷰가 나오면 시트로 못 쓴다
```

```
This character is ALIVE            ← 언데드 금지. 기존 C3 가 언데드였을 뿐이다
face IN SHADOW inside the hood     ← 후드 유지, 얼굴 디테일은 그리지 않는다
```

### 컨셉 — 살아있는 마법 궁수(주문궁수)

**언데드가 아니다.** 이전 시안(C3)이 언데드 궁수였을 뿐이고, 이번엔 그 설정을
쓰지 않는다. `DO NOT` 목록에 해골·유령·좀비·반투명 다리를 전부 넣어뒀다.

발광색은 **`#e05cff` (자마젠타)** 로 고정이다. `main.js` 색조 전수조사에서
280~339° 가 통째로 비어 있었고, 회녹색 바닥의 보색이라 대비가 최대다.

언데드를 버리면서 **발광의 근거를 바꿨다.** 예전엔 "영혼불"이었는데 지금은
**마력이 깃든 활**이다 — 활 몸통의 룬, 은은하게 빛나는 활시위, 그리고 발광이
나타나는 곳을 딱 세 군데로 못박았다:

```
후드 안쪽(눈)  ·  장비의 얇은 룬 선  ·  활을 든 손의 마력 잔광
```

세 군데로 한정한 이유는 실측 때문이다. 발광 면적이 15% 를 넘으면 보라가 번져서
실루엣을 먹는다. 목표는 **3~9%** 다.

## 3. 받은 뒤 — 판정

`docs/캐릭터_재설계_SD.md` §8 의 스크립트를 그대로 쓴다.
`cands/` 안의 `design_*.png` 뿐 아니라 `gem_*.png` 도 잡히도록 glob 만 바꾸면 된다.

```
다리분리    ≥ 35%      ← ★ 옛 idle.png 는 0.6% 였다
다리대비    ≥ 12
몸통명도    50 ~ 58    (바닥 42.3)
국소대비    ≥ 14       ← **게임 크기 64px 에서** 잰 값이다. 원본에서 재면 안 된다
발광 면적   3 ~ 9%
```
