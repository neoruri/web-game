공통으로 적용한 개선

• 확인 버튼 제거 — 스킬을 탭하면 즉시 장착. 되돌리기는 일시정지에서.
• 탭 없는 단일 화면 — 이전 시안의 “①/② 탭”은 목업 편의였을 뿐, 실제로는 서로 다른 시점의 화면.
• 수치 델타 표시 — 스킬을 고를 때 DPS/쿨타임 변화를 미리 보여준다.
• 교체 경고 — 이미 룬이 있는 스킬은 “교체” 표시(빠진 룬은 가방으로).

지금 프로젝트에 대한 권장

룬이 5종뿐이라 랜덤은 중복 체감이 커서 A(3개 중 선택)를 권합니다. 대신 A의 탭 수를 2탭으로 줄이고 확인 버튼을 없애면 B와의 체감 차이가 크지 않습니다.
나중에 룬이 10종 이상 + 티어가 생기면 B(랜덤)로 전환하는 게 자연스럽습니다. 그때는 “획득은 랜덤, 배치는 일시정지에서 자유롭게”가 정석 구조입니다.
