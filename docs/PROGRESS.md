# 진행 상태 (compact/세션 인계용)

> 이 파일이 "진실의 원천". 대화가 compact 돼도 여기만 읽으면 상태 복구 가능.
> 최종 갱신: 2026-07 (화살 발사 버그 근본 수정 + 스킬트리 기획 완료 시점)

배포: https://web-game-tau-sable.vercel.app (game) · /tuner.html · /lab.html
스택: Vite + Vanilla JS + Phaser 3. main→vercel 자동 배포.

## ✅ 완료 (구현·검증·배포됨)

**게임 코어**
- 뱀서류 프로토타입: 이동(WASD+가상조이스틱), 자동 활 발사, 적 추격, 보스
- 액티브 스킬 3종 → 시간차 연사(다-다-다), 가까운 적 조준
  · 다발사격(부채꼴) / 연발사격(단일 연사, 신규) / 난사(360° 지속) / 수류탄
- 젬 제거 → **처치 즉시 경험치**
- 몬스터 **겹침 방지**(분리력, 그리드 6마리 조회)

**성장 시스템 (스펙 3단계까지)**
- 1단계: 능력치 4종(힘/민첩/지능/활력) 포인트 투자, 성장 화면(C키/버튼, DOM 모달)
- 2단계: 스킬 트리(3계열 사격/기동/폭발물, 액티브4+패시브, 5레벨 특화, 레벨 해금·선행조건)
- 3단계: 능력치 구간 보너스(힘10~40, 민첩10~40 등: 치명타·회피·부활·처치폭발·쿨환급 등)
- deriveStats() 단일 재계산 함수. UI(growth-ui)와 계산(progression) 분리.

**툴 (우리 고유 강점)**
- 튜너 /tuner.html: 슬라이더 실시간, 효과 설명, 프리셋 A/B/C
- 랩 /lab.html: 밸런스 곡선(예측) + **자동 시뮬레이터**(봇 실측, 판당 ~60ms)

**DemonHunting(GPT판) 대비 개선 항목 — 순서 1~4 중:**
- ✅ 순서1: **진짜 카메라(무한 월드)** — 월드 컨테이너 방식, 플레이어 화면 중앙 고정
- ✅ 순서2: **적 투사체 + 보스 라인 탄막**(예고→실탄)
- ✅ 순서3a: **적 3종**(기본/돌진/원거리 카이팅) + 유기적 흔들림 + 단계별 등장(0/30/75초)

**버그 수정 (중요)**
- ★ **화살 발사 중단 근본 원인**: updateArrows가 화살을 화면 좌표로 제거 → 무한 월드에서
  플레이어 이동 시 화살 즉시 삭제. 플레이어 거리 기준으로 수정. (게임+시뮬 봇 딜 동시 해결)
- 수류탄 다발 크래시(적 다 죽으면 undefined 참조) 수정
- localStorage 키 v1→v2 (옛 저장값 강제 초기화), 무기 사거리 380→620(화면 덮게)

## 📁 파일 맵

```
src/
  main.js         게임 씬 전체 (렌더/전투/스킬/성장 통합)
  config.js       모든 수치 DEFAULTS + 튜너 SCHEMA + 프리셋. KEY='survivor.config.v2'
  progression.js  능력치·구간보너스 → 전투수치 재계산 (deriveStats)
  skilltree.js    스킬 트리 데이터 (액티브/패시브/특화)
  upgrades.js     (구) 카드 — SKILL_IDS 등 일부만 사용
  sim.js          자동 시뮬레이터 코어 (main 로직 복제, 봇 AI)  ⚠ main 수정 시 동기화 필수
  grid.js         공간분할 충돌 그리드 (setOrigin으로 무한월드 대응)
  growth-ui.js    성장 화면 DOM 모달 (능력치탭 + 스킬트리탭)
  growth.css / tuner.* / lab.*  각 페이지
docs/
  PROGRESS.md              ← 이 파일
  skill_tree_design.md     보더랜드2식 3계열 트리 기획(레벨별 수치)
  plan_movement_and_assets.md  겹침방지(완료)·AI에셋(미)
  survivor_game_plan.md    초기 전체 로드맵
```

## ⚠ 작업 시 주의
- **main.js와 sim.js는 전투/스폰/성장 로직이 동일해야 한다.** 한쪽 고치면 다른 쪽도.
- 좌표는 전부 **월드 좌표**. 화면 좌표(0~540/0~960)로 판정하면 무한월드에서 버그(화살 사건 재발).
- 새 수치는 config DEFAULTS + SCHEMA 양쪽에. 밸런스 크게 바꾸면 KEY 버전 올려 저장값 초기화.
- 스크린샷 검증은 이 환경에서 자주 타임아웃 → JS로 상태값 검증하는 방식 사용.
