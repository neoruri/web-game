브라우저에서 실행되는 2D 탑다운 뱀서류 로그라이크 웹게임에 성장 시스템을 추가해줘.

게임의 성장 구조는 고전 액션 RPG처럼 능력치 포인트와 스킬 포인트를 직접 투자하는 방식으로 구성하고, 전투와 스킬 연출은 빠르고 화려한 원거리 사냥꾼 스타일로 구현한다.

특정 상용 게임의 캐릭터, UI, 스킬 아이콘, 명칭, 사운드, 이미지, 애니메이션을 그대로 복제하지 말고, 아래 시스템과 전투 감각만 참고하여 독창적으로 제작한다.

*전체적인 제작 컨샙은 디아블로2 시스템과 디아블로3 악마사냥꾼 스킬 트리를 컨셉으로 벤치마킹해서 진행 예정

**제작 할 때 1순위는 최적화를 최대한 신경 써서 진행 한다**

# 1. 핵심 성장 방향

레벨업 시 무작위 카드 하나만 고르는 방식이 아니라, 플레이어가 능력치 포인트와 스킬 포인트를 직접 배분하는 구조로 변경한다.

레벨업할 때마다 다음 보상을 지급한다.

- 능력치 포인트 +3
- 스킬 포인트 +1

레벨업 직후 게임을 강제로 멈추지는 않는다.

화면에 다음 알림만 표시한다.

LEVEL UP
능력치 포인트 +3
스킬 포인트 +1

획득한 포인트는 누적해서 저장한다.

플레이어가 다음 방법으로 성장 화면을 직접 열 수 있게 한다.

- 키보드 C
- HUD의 성장 버튼 클릭
- 일시정지 메뉴의 성장 메뉴 선택

성장 화면이 열리면 게임은 완전히 일시정지한다.

# 2. 능력치 시스템

플레이어는 다음 네 가지 능력치를 가진다.

- 힘
- 민첩
- 지능
- 활력

각 능력치는 기본 수치 0부터 시작한다.

능력치 포인트 1개를 사용할 때 해당 능력치가 1 증가한다.

능력치 포인트는 자유롭게 배분할 수 있다.

예:

- 힘 +3
- 힘 +1, 민첩 +1, 활력 +1
- 지능 +3

성장 화면에서 [+] 버튼을 눌러 포인트를 배분한다.

적용 버튼을 누르기 전까지는 임시 투자 상태로 유지한다.

취소 버튼을 누르면 이번에 배분한 포인트를 원래 상태로 되돌린다.

적용 버튼을 누르면 투자 내용을 확정한다.

확정한 능력치 투자는 일반 플레이 중에는 되돌릴 수 없도록 한다.

개발 테스트를 위해 CONFIG에서 무료 초기화 기능을 켜고 끌 수 있게 한다.

# 3. 힘

힘은 전체 공격 피해를 강화한다.

힘 1포인트당:

- 기본 활 공격 피해 +1.5%
- 모든 자동 스킬 피해 +1.5%

힘 구간 보너스:

- 힘 10: 치명타 피해 +10%
- 힘 20: 모든 피해 추가 +10%
- 힘 30: 모든 투사체 관통 +1
- 힘 40: 적 처치 시 8% 확률로 작은 폭발 발생

힘 40의 처치 폭발:

- 처치한 적 위치에서 발생
- 작은 범위 피해
- 연쇄 폭발은 발생하지 않음
- 내부 쿨타임 0.2초 적용
- 성능 저하를 막기 위해 동시 폭발 수 제한

# 4. 민첩

민첩은 기본 활 공격 속도와 이동 능력을 강화한다.

민첩 1포인트당:

- 기본 활 공격 속도 +0.7%
- 이동 속도 +0.25%

민첩 구간 보너스:

- 민첩 10: 치명타 확률 +3%
- 민첩 20: 이동 속도 추가 +5%
- 민첩 30: 기본 활 추가 화살 +1
- 민첩 40: 피해 회피 확률 +8%

민첩의 공격 속도 증가는 기본 활 공격에만 적용한다.

다발 사격, 연발 사격, 난사, 수류탄의 쿨타임에는 적용하지 않는다.

공격 속도 증가 상한:

- 최대 +75%

이동 속도 증가 상한:

- 최대 +35%

회피가 발동하면:

- 피해를 받지 않음
- 플레이어 주변에 짧은 잔상 효과 표시
- DODGE 텍스트 표시

# 5. 지능

지능은 자동 스킬의 쿨타임과 효과를 강화한다.

지능 1포인트당:

- 자동 스킬 쿨타임 감소 +0.5%

지능 구간 보너스:

- 지능 10: 모든 스킬 피해 +8%
- 지능 20: 모든 스킬 범위 +10%
- 지능 30: 지속형 스킬 지속시간 +15%
- 지능 40: 스킬 발동 시 10% 확률로 해당 스킬 쿨타임 50% 반환

쿨타임 감소 상한:

- 일반 상한 40%
- 특별 강화 포함 최종 상한 50%
- 어떤 스킬도 최종 쿨타임이 1초보다 짧아지지 않음

쿨타임 계산:

최종 쿨타임 = 기본 쿨타임 × (1 - 최종 쿨타임 감소율)

지능 40 효과:

- 스킬 발동 순간 판정
- 발동한 스킬의 남은 쿨타임을 50% 감소
- 내부 쿨타임 5초
- 같은 스킬이 연속으로 무한 발동하지 않도록 방어 처리

# 6. 활력

활력은 최대 체력과 생존력을 강화한다.

활력 1포인트당:

- 최대 HP +2

활력 증가 시 현재 HP도 증가한 최대 HP만큼 함께 올려준다.

활력 구간 보너스:

- 활력 10: 초당 HP 회복 +0.5
- 활력 20: 받는 피해 -5%
- 활력 30: 초당 HP 회복 추가 +0.5
- 활력 40: 치명적인 피해를 한 번 버티고 최대 HP의 30% 회복

활력 40 생존 효과:

- HP가 0 이하가 되는 피해를 받을 때 발동
- 사망하지 않고 최대 HP의 30% 회복
- 2초간 무적
- 재사용 대기시간 60초
- HUD에 준비 여부와 남은 쿨타임 표시

초당 체력 회복은 deltaTime 기준으로 정확히 계산한다.

# 7. 스킬 포인트 시스템

레벨업마다 스킬 포인트 1개를 획득한다.

스킬 포인트는 누적할 수 있다.

스킬 포인트는 다음 용도로 사용한다.

- 신규 스킬 획득
- 기존 스킬 레벨 강화
- 패시브 노드 강화
- 스킬 특화 선택

모든 스킬을 한 판에 완성할 수 없도록 전체 필요 포인트를 충분히 높게 설계한다.

권장 기준:

- 플레이어 최고 레벨 30
- 획득 가능한 스킬 포인트 약 29개
- 전체 스킬 트리 완성에는 40포인트 이상 필요

이를 통해 매 플레이마다 다른 빌드가 만들어지도록 한다.

# 8. 스킬 해금 레벨

스킬은 캐릭터 레벨에 따라 해금한다.

- 레벨 1: 다발 사격
- 레벨 5: 연발 사격
- 레벨 10: 난사
- 레벨 15: 수류탄

게임 시작 시 다음을 기본 제공한다.

- 기본 활 공격
- 다발 사격 1레벨

레벨 5, 10, 15에 도달하면 화면에 신규 스킬 해금 알림을 표시한다.

예:

NEW SKILL UNLOCKED
연발 사격
성장 화면에서 스킬 포인트를 사용해 배울 수 있습니다.

새로 해금된 스킬을 자동으로 배우게 하지 않는다.

플레이어가 스킬 포인트를 사용해 직접 획득하도록 한다.

# 9. 스킬 트리 구조

스킬 트리는 세 계열로 구성한다.

## 사격 계열

- 궁술 숙련
- 다발 사격
- 연발 사격
- 관통 화살
- 치명타 훈련

## 기동 계열

- 회피 훈련
- 난사
- 이동 속도 강화
- 피격 후 가속
- 전투 회피

## 폭발물 계열

- 폭발물 숙련
- 수류탄
- 폭발 범위 강화
- 화염 지대
- 파편 폭발

스킬 트리의 연결선은 성장 방향을 보여주는 시각적 요소로 사용한다.

선행 스킬 투자 강제 조건은 최소화한다.

기본 해금 조건은 캐릭터 레벨로 한다.

일부 고급 패시브만 다음 조건을 사용할 수 있다.

예:

- 관통 화살: 다발 사격 3레벨 필요
- 치명타 훈련: 궁술 숙련 2레벨 필요
- 화염 지대: 수류탄 3레벨 필요
- 전투 회피: 회피 훈련 2레벨 필요

필수 선행 조건이 너무 많아 플레이어가 원하지 않는 스킬을 찍게 만들지 않는다.

# 10. 다발 사격

다발 사격은 전방 광역 공격 스킬이다.

가장 가까운 적 방향을 기준으로 넓은 부채꼴 범위에 화살을 발사한다.

기본 쿨타임:

- 3초

스킬 최대 레벨:

- 10

레벨별 효과:

- 1레벨: 화살 5발
- 2레벨: 화살 6발
- 3레벨: 피해 +15%
- 4레벨: 화살 7발
- 5레벨: 특화 선택 해금
- 6레벨: 관통 +1
- 7레벨: 화살 9발
- 8레벨: 피해 +20%
- 9레벨: 적중 시 작은 파편 화살 생성
- 10레벨: 중앙 화살이 적중 시 폭발

5레벨 특화 선택:

A. 집중 사격
- 발사 각도 감소
- 중앙 화살 피해 +50%
- 정예와 보스에게 추가 피해

B. 확산 사격
- 발사 각도 증가
- 화살 수 +3
- 각 화살 피해 -10%

특화 선택은 하나만 가능하다.

선택 후 다른 특화로 변경할 수 없다.

# 11. 연발 사격

연발 사격은 단일 대상 집중 공격 스킬이다.

가장 가까운 적 또는 체력이 높은 적을 자동 조준한다.

짧은 시간 동안 빠르게 연속 발사한다.

기본 쿨타임:

- 4초

스킬 최대 레벨:

- 10

레벨별 효과:

- 1레벨: 화살 5발
- 2레벨: 화살 6발
- 3레벨: 연사 속도 증가
- 4레벨: 화살 7발
- 5레벨: 특화 선택 해금
- 6레벨: 관통 +1
- 7레벨: 화살 9발
- 8레벨: 동일 대상 연속 적중 피해 증가
- 9레벨: 마지막 화살 피해 +150%
- 10레벨: 마지막 화살이 폭발

5레벨 특화 선택:

A. 추적 연사
- 현재 대상이 죽으면 남은 화살이 다음 가까운 적을 자동 추적

B. 집중 연사
- 같은 대상에게 연속 적중할 때마다 피해 증가
- 최대 5중첩
- 보스전 특화

# 12. 난사

난사는 플레이어 주변 360도 공격 스킬이다.

플레이어가 이동하면서 주변 모든 방향으로 화살을 발사한다.

기본 쿨타임:

- 7초

스킬 최대 레벨:

- 10

레벨별 효과:

- 1레벨: 1.5초 지속
- 2레벨: 발사 빈도 증가
- 3레벨: 피해 +15%
- 4레벨: 지속시간 1.8초
- 5레벨: 특화 선택 해금
- 6레벨: 화살 관통 +1
- 7레벨: 이동 속도 +10%
- 8레벨: 지속시간 2.2초
- 9레벨: 발사 빈도 추가 증가
- 10레벨: 종료 시 원형 충격파 발생

5레벨 특화 선택:

A. 그림자 난사
- 플레이어 뒤에 잔상이 생성
- 잔상이 추가 화살 발사
- 시각적으로 회전하는 그림자 분신 표현

B. 방어 난사
- 난사 중 받는 피해 -30%
- 난사 중 피격 무적시간 증가

# 13. 수류탄

수류탄은 적이 밀집된 위치를 공격하는 범위 스킬이다.

일정 범위 내에서 적이 가장 많이 모인 위치를 찾아 자동 투척한다.

포물선 궤적으로 이동한 뒤 폭발한다.

기본 쿨타임:

- 5초

스킬 최대 레벨:

- 10

레벨별 효과:

- 1레벨: 수류탄 1개
- 2레벨: 폭발 범위 +10%
- 3레벨: 피해 +15%
- 4레벨: 수류탄 2개
- 5레벨: 특화 선택 해금
- 6레벨: 폭발 범위 추가 증가
- 7레벨: 화염 지대 생성
- 8레벨: 수류탄 3개
- 9레벨: 폭발 중심부 추가 피해
- 10레벨: 파편 폭탄 생성

5레벨 특화 선택:

A. 집속 폭탄
- 폭발 범위 감소
- 중심부 피해 대폭 증가
- 보스와 정예 몬스터 특화

B. 확산 폭탄
- 수류탄이 착탄 후 작은 수류탄으로 분열
- 넓은 지역 공격
- 일반 몬스터 처리 특화

# 14. 패시브 스킬

패시브 스킬도 스킬 포인트를 사용해 투자한다.

## 궁술 숙련

최대 5레벨:

- 레벨당 기본 활 피해 +5%
- 레벨당 투사체 속도 +3%

## 관통 화살

최대 3레벨:

- 레벨당 기본 활과 사격 계열 관통 +1
- 다발 사격 3레벨 필요

## 치명타 훈련

최대 5레벨:

- 레벨당 치명타 확률 +2%
- 최대 +10%

## 회피 훈련

최대 5레벨:

- 레벨당 회피 확률 +1%
- 최대 +5%

## 이동 속도 강화

최대 5레벨:

- 레벨당 이동 속도 +2%

## 피격 후 가속

최대 3레벨:

- 피격 후 2초 동안 이동 속도 증가
- 레벨당 +5%

## 폭발물 숙련

최대 5레벨:

- 레벨당 수류탄 피해 +5%

- 폭발 시 파편 개수 증가
- 각 파편은 주변 적에게 피해

# 18. 신규 스킬 해금 연출

레벨 5, 10, 15 도달 시 화면 중앙에 짧은 해금 연출을 표시한다.

연출 중 게임은 멈추지 않는다.

표시 시간:

- 약 2초

예:

NEW SKILL UNLOCKED
난사
성장 화면에서 습득할 수 있습니다.

해금 알림이 끝난 뒤 성장 버튼을 잠시 강조한다.

# 19. 전투 연출 방향

전체 전투는 빠르고 화려한 원거리 전투 느낌으로 구성한다.

특정 상용 게임의 이펙트를 그대로 복제하지 않는다.

다발 사격:

- 넓은 부채꼴 궤적
- 청백색 화살
- 발사 순간 짧은 충격파

연발 사격:

- 빠른 연속 궤적
- 동일 대상 연속 적중 시 타격 효과 강화
- 마지막 화살은 더 밝고 크게 표현

난사:

- 플레이어 주변 회전 잔상
- 360도 화살 발사
- 어두운 붉은색과 청백색 원형 효과

수류탄:

- 포물선 궤적
- 착탄 전 경고 원
- 주황색과 붉은색 폭발
- 파편과 연기
- 강한 폭발에만 화면 흔들림

피해 숫자:

- 일반 피해는 작게
- 치명타는 크게
- 너무 많은 숫자가 겹치지 않도록 제한
- 동일한 적에게 짧은 시간 내 발생한 피해는 일부 합산 가능

# 20. 레벨업 처리 예외

한 번에 많은 경험치를 획득해 여러 레벨이 상승할 수 있다.

이 경우:

- 상승한 레벨 수만큼 능력치 포인트와 스킬 포인트를 모두 지급
- 레벨업 창을 여러 번 반복해서 띄우지 않음
- 한 번의 LEVEL UP 알림으로 통합
- 예: LEVEL UP +3
- 능력치 포인트 +9
- 스킬 포인트 +3

스킬 해금 레벨을 건너뛴 경우에도 해당 스킬을 정상 해금한다.

예:

레벨 9에서 레벨 11로 상승한 경우 난사 해금 처리

# 22. 구현 조건

- 기존 게임 기능을 삭제하지 말 것
- 성장 시스템을 모듈화할 것
- UI와 실제 능력치 계산을 분리할 것
- 임시 투자값과 확정 투자값을 분리할 것
- 적용 전에는 실제 전투 수치가 바뀌지 않게 할 것
- 모든 최종 수치는 한 곳에서 재계산하는 함수로 관리할 것
- 포인트가 부족하면 투자할 수 없게 할 것
- 최대 레벨을 넘길 수 없게 할 것
- 잠긴 스킬에 투자할 수 없게 할 것
- 선행 조건을 충족하지 않으면 투자할 수 없게 할 것
- 특화 선택은 한 번만 가능하게 할 것
- 게임 재시작 시 모든 성장 데이터를 초기화할 것
- 개발 편의를 위해 시작 레벨, 시작 포인트, 스킬 해금 상태를 CONFIG에서 조정 가능하게 할 것
